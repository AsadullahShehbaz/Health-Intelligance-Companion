🏥 Health Intelligence Companion — FYP Roadmap

8 Weeks · From Scratch to Submission · Asadullah Shehbaz

MONTH 1 — BUILD THE BRAIN
Week 1 DATA COLLECTION
📦 Dataset Setup & Environment
  • Download ChatDoctor 100k from HuggingFace
  • Download MedQA, MedMCQA, MedDialog, iCliniq, PubMedQA
  • Setup Kaggle notebook environment
  • Install: transformers, peft, bitsandbytes, trl, datasets
  • Explore + clean each dataset (remove noise, duplicates)
  • Setup project GitHub repo with proper structure
  • Setup PostgreSQL locally for development
All raw datasets downloaded + cleaned + GitHub repo live
Week 2 DATA PREP
🔧 Data Formatting + Urdu Synthetic Data
  • Convert ALL datasets to instruction format (instruction/input/output JSON)
  • Output format: diagnosis + confidence + reasoning + medicines + diet + exercise
  • Generate 5000 Urdu/Roman Urdu synthetic QA pairs via GPT-4o API
  • Merge all datasets into single training file
  • Split: 90% train / 10% validation
  • Final dataset size: ~65-80k samples
Single merged instruction-format dataset ready for training
Week 3 FINE-TUNING 🔥
🧠 QLoRA Fine-Tune BioMistral-7B
  • Load BioMistral-7B with 4-bit quantization on Kaggle 2x T4
  • Configure LoRA: r=16, alpha=32, target q/k/v/o projections
  • Run training: 3 epochs, batch=4, grad_accum=4, lr=2e-4
  • Monitor loss curves every 10 steps
  • Save checkpoints every 100 steps
  • Run 2nd training pass if validation loss not satisfactory
  • Push final adapter weights to HuggingFace Hub
Fine-tuned BioMistral-7B adapter weights saved on HuggingFace
Week 4 RAG PIPELINE
📚 RAG + Vector Store Setup
  • Download PubMed Open Access + WHO Guidelines + OpenFDA + MedlinePlus
  • Chunk documents: 512 tokens, 50 token overlap
  • Embed with BGE-M3 (multilingual, supports Urdu)
  • Store in Qdrant vector store (local instance)
  • Add BM25 hybrid retrieval alongside dense retrieval
  • Add BGE-Reranker for top-k result reranking
  • Test retrieval: medicines, dosages, herbal remedies queries
RAG pipeline retrieving accurate medical info from Qdrant
MONTH 2 — BUILD THE SYSTEM
Week 5 LANGGRAPH AGENT
🤖 Multimodal Input + LangGraph Agent
  • Build Whisper voice-to-text pipeline
  • Build TrOCR handwritten prescription reader
  • Build PyMuPDF lab report PDF parser
  • Build LangGraph 9-node agent graph
  • Node 1: Patient ID → Node 2: Input Processing → Node 3: Symptom Elicitation
  • Node 4: Context Assembly → Node 5: Diagnosis → Node 6: RAG Retrieval
  • Node 7: Treatment Plan → Node 8: Memory Update → Node 9: Response
  • Add conditional loops for follow-up questioning
Full LangGraph agent running end-to-end (text input only first)
Week 6 POSTGRESQL MEMORY
🗃️ Memory Layer + Full Integration
  • Create all PostgreSQL tables: patients, sessions, medical_history, emotional_memory
  • Wire LangGraph Node 1 to READ patient full history from PostgreSQL
  • Wire LangGraph Node 8 to WRITE session summary to PostgreSQL
  • Connect multimodal inputs (Whisper + TrOCR) to agent pipeline
  • Test full flow: voice input → diagnosis → treatment → memory saved
  • Fix all integration bugs between components
Complete pipeline working: input → agent → diagnosis → PostgreSQL memory saved
Week 7 BACKEND + FRONTEND
⚙️ FastAPI + Streamlit Interface
  • Build FastAPI endpoints: /chat, /upload-document, /patient-history, /diagnosis
  • Add JWT authentication for patient login
  • Build Streamlit frontend: chat interface + document upload + history view
  • Display diagnosis with confidence score visualization
  • Display treatment plan: medicines + diet + exercise tabs
  • Connect frontend → FastAPI → LangGraph agent → PostgreSQL
  • Test complete user journey end-to-end
Working web app: patient can chat, upload docs, get diagnosis + treatment plan
Week 8 EVALUATION + DOCS
📊 Testing + Evaluation + Submission
  • Run RAGAS evaluation: faithfulness, answer relevancy, context precision
  • Manual testing: 50 real patient scenarios in Urdu + English
  • Test edge cases: incomplete history, contradictory symptoms
  • Fix critical bugs found during evaluation
  • Write FYP report: problem, methodology, architecture, results
  • Record demo video of complete system
  • Deploy demo on HuggingFace Spaces
  • Prepare viva presentation (10 slides max)
Submitted FYP + Live Demo + Evaluation Report + Viva Ready
